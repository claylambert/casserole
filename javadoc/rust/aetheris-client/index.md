# Crate aetheris-client

[Rust tree](../index.md) · **aetheris-client**

**Source** `aetheris/rust/aetheris-client/src/main.rs`

The `main` function starts the VT100 window for one Casserole session.

The binary name is `aetheris-client`. The grid lives in the `aetheris-term` crate. The token ring reads `casserole.grok.context-windows` and `casserole.pool.context-window` from `application.yaml`. It drops every other key. This crate does not open a socket to Ollama. This crate does not call the Grok API.

enum PromptBytes

The `PromptBytes` enum is the classified contents of a prompt file.
[`PromptBytes::Text`](#member-text) holds the bytes that were read. [`PromptBytes::Binary`](#member-binary) means a NUL was found and this value holds no bytes.

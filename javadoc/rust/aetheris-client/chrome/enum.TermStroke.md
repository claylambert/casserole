# enum TermStroke

```rust
enum TermStroke
```

The enum `TermStroke` is one console input after the event list has been read. `Text` is characters to encode. `Key` is one terminal key. `Paste` is clipboard text waiting for the paste dialog. `Copy` copies the highlight and writes no byte. `Motion` is a console menu label that stays on this pane and writes no byte.

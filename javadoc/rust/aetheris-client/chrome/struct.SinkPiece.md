# struct SinkPiece

[Rust tree](../../index.md) · [aetheris-client](../index.md) · **chrome**

**Source** `aetheris/rust/aetheris-client/src/chrome.rs`

```rust
struct SinkPiece
```

The struct `SinkPiece` is one row while `sink_inspect` chooses what to keep.
The index `ordinal` is the order the row was built. The number `seq` is the sequence number. The byte `role` comes from `sink_role`. The count `tokens` comes from `estimate_tokens`.

The flag `head` is the lock copied from the block. The flag `stay` marks a user row that still starts with a mood line. The flag `live` marks the current user piece. The word `role_name` is the original role. The string `text` is the row text.

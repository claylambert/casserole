# struct ViewPane

```rust
struct ViewPane
```

The struct `ViewPane` is one open reply window.
The window paints this value. Closing the window stores `last`.

The field `index` is the card whose reply is shown.
The field `body` is that reply text.
The field `find` is the [`ViewFind`](struct.ViewFind.md) for this window.
The field `place` is true when a saved rectangle should be applied on the next paint.
The field `saved` is that saved [`ViewRect`](struct.ViewRect.md), or `None` when there is none.
The field `last` is the rectangle after the latest paint, or `None` before the window has been shown.

```rust
struct ImportOutcome
```

The struct `ImportOutcome` is the result of one prompt import.
`begin_import` returns it.

The field `status` is the status line.
`status` is `None` when the card is missing or the chooser is canceled.
The field `door_failed` is true when the chooser rectangle or the chosen folder could not be saved.
The field `red` is true for a thrown read, and that failure opens a red notice.
A refusal leaves `red` false.

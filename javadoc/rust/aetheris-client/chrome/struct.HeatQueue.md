# struct HeatQueue

struct HeatQueue
```

The struct `HeatQueue` listens to heatbar edits on a background thread.
The field `inner` is the shared [`HeatInner`](struct.HeatInner.md). The field `thread` holds the worker handle once the thread has been started. The newest pending edit is the one that runs.

A call on the window thread does not wait for the worker. The worker is joined when this value is dropped.

### ensure

The method `ensure` starts the worker thread once.
A handle that is already present returns immediately. A missing handle spawns a thread named `aetheris-heat`. That thread runs `heat_worker`. A spawn failure panics with `heat thread`.

The method `offer` posts one beat and wakes the worker.

### poll

```

The method `poll` takes a finished paint when it is still the newest beat.
A ready paint whose sequence number equals `current` is taken, and `ready` becomes empty. Any other state returns `None`. A ready paint for an older sequence number is left in place.

### finish_pending

<a id="method-finish_pending"></a>

```rust
fn finish_pending(&self) -> Option<HeatPaint>
```

The method `finish_pending` waits until the newest beat has been stored, or until three seconds pass.
The test frame uses this wait. `ensure` starts the worker first. Each wait on the condition variable is 50 milliseconds.

An empty `pending` and a clear `busy` flag end the wait. A ready paint whose sequence number equals `current` is then taken. Any other finished state returns `None`. A wait past three seconds returns `None`.

The method `drop` stops the worker and joins it.

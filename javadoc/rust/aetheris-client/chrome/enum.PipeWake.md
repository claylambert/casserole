# enum PipeWake

```rust
enum PipeWake
```

The enum `PipeWake` is what the window should do after a chain card finishes.
`pipe_after_doc` returns it.

[`PipeWake::Quiet`](#member-quiet) means no further frame is sent.
[`PipeWake::Send`](#member-send) carries the next cell id and the next frame bytes.
[`PipeWake::Status`](#member-status) carries a status word and stops the chain.

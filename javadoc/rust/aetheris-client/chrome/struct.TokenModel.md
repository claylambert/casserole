struct TokenModel

The struct `TokenModel` is one model row in the token window.
The string `label` is the row name. The string `family` is `ollama`, `grok`, or `pool`. The integer `window` is the context window. The flag `window_known` is true when that window is a positive count.

The integer `completion_cap` is the completion cap. The flag `completion_known` is true when that cap is a positive count.

The method `new` builds one [`TokenModel`](struct.TokenModel.md) and normalizes the two windows.
The string `label` is the row name. The string `family` is the provider family. The integer `window` is the context window. The flag `window_known` is the caller claim that the window is known. The integer `completion_cap` is the completion cap. The flag `completion_known` is the caller claim that the cap is known.

A negative window is stored as 0. `window_known` is stored only when the caller flag is true and the stored window is above 0. `completion_known` is stored only when the caller flag is true and `completion_cap` is above 0. A non-positive cap stays on the struct, with the known flag false.

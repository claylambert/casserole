# struct CanvasHeat

[Rust tree](../../index.md) · [aetheris-client](../index.md) · **chrome**

```rust
struct CanvasHeat
```

The struct `CanvasHeat` is one canvas beat for the heatbar worker.
The vectors `prompts`, `replies`, `marks`, `groups`, and `columns` are the card rows. The index `focus` is the focused card. The record `mood` is the [`MoodYaml`](struct.MoodYaml.md) copied onto the beat.

The count `line_chars` is the preview width. The option `debug` is a block index plus the invitation lines. The flag `pin_active` chooses the pin view. The vector `shown` is the pin visibility of each card. The vector `locks` is the lock flag of each card. The integer `managed` is the token budget. Zero closes the sink.

# struct DeckRefs

[Rust tree](../../index.md) · [aetheris-client](../index.md) · **chrome**

**Source** `rust/aetheris/aetheris-client/src/chrome.rs`

```rust
struct DeckRefs<'a>
```

The `DeckRefs` struct is a mutable view of one canvas deck while scope is applied.
`cards` is the turn list. `focus` is the focused card index. `facts` is the seated canvas facts. `scope_text` is the gathered scope text. `think` is the [`ThinkLog`](struct.ThinkLog.md).

`group_live` is the group id that is running. Zero means no group is running. `group_rest` holds the remaining group frames as a cell id plus bytes. `pipe_live` is true while a pipe chain is running. `pipe_rest` is the card indexes still waiting. `focus_prompt` is true when the prompt should take the keyboard. `land_newest` is true when the next paint should scroll to the newest card.

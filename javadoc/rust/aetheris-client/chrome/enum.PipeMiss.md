# enum PipeMiss

enum PipeMiss

The enum `PipeMiss` is why one chain card could not be framed.
`pipe_frame` returns it as the error.

[`PipeMiss::Blocked`](#member-blocked) means a pipe token could not be resolved.
[`PipeMiss::Excluded`](#member-excluded) means the card produced no working blocks.
[`PipeMiss::NoModel`](#member-nomodel) means the card's target names no model.

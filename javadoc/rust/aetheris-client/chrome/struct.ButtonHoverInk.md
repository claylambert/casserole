The struct `ButtonHoverInk` is the button theme that paints emerald words on hover.
An ordinary button takes that emerald while the pointer is on it or while the button is active. A tab keeps its own word color. A menu title keeps its own word color. The I, E, P, and O marks take that emerald while the pointer is on them, even though those marks are selectable.

The method `style` returns the button style for one widget state.
`args` carries the classes, the parent stack, and the widget state. The style starts from the default button style.
A button is selectable when it has the selected class or the class that hides the frame while inactive. A button is a mark when it has the class `aetheris.mark`. A button is in a menu when a parent is a menu.
Hovered and active are the hot states. A hot button that is not in a menu, and that is not selectable, takes the emerald word color. A hot mark takes that same emerald even when it is selectable. Every other button keeps the default word color.

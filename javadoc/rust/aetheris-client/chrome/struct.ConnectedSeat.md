struct ConnectedSeat

The struct `ConnectedSeat` is one SSH connection the pull-down can list.
The window builds the list from the focused pane and each parked pane. A test passes two records so the list rule matches the Java list.

The field `name` is the raw name. The field `connected` says the connection is up. The field `amwp` says the connection speaks that protocol. The field `focused` says this record is the focused pane.

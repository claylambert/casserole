# enum ChainAsk

enum ChainAsk

The enum `ChainAsk` is the next action for a pipe chain.
`plan_chain_doc` and `take_next` return it.

[`ChainAsk::Busy`](#member-busy) means a card is already running, or the focus is past the list.
[`ChainAsk::Excluded`](#member-excluded) means the card is excluded or has no working blocks.
[`ChainAsk::TooLarge`](#member-toolarge) means the fitted frame is absent.
[`ChainAsk::Pipe`](#member-pipe) means a pipe token blocked the send.
[`ChainAsk::Quiet`](#member-quiet) means there is nothing left to send, including a focused merge card.
[`ChainAsk::NoModel`](#member-nomodel) means the card names no model.
[`ChainAsk::Send`](#member-send) carries the cell id, the frame bytes, and the indexes still queued.

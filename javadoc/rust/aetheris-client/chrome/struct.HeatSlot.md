# struct HeatSlot

```rust
struct HeatSlot
```

The struct `HeatSlot` is the shared state of the heatbar worker.
The option `pending` is the beat waiting to run. The number `current` is the sequence number of the newest beat. The option `ready` is a finished [`HeatPaint`](struct.HeatPaint.md). The flag `busy` is true while a beat is being counted. The flag `stop` asks the worker to exit.

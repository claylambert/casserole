# struct AppleSeat

```rust
struct AppleSeat
```

The struct `AppleSeat` is the last frame of one apple bar.
The drag reads it. The paint uses the frame that just closed. `offset` is the scroll offset. `inner_min` and `inner_size` are the inner rectangle. `content` is the content size.

enum ConsoleReadFail

The `ConsoleReadFail` enum is why a console import did not return text.
[`ConsoleReadFail::Refuse`](#member-refuse) holds a static refusal such as a binary file or an empty file. [`ConsoleReadFail::Failed`](#member-failed) holds the message from a read that did not complete.

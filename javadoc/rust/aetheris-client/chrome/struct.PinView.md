struct PinView

The struct `PinView` is one frame of the pin.
The canvas and the inspector both read it. The field `active` says the filter is on. The field `shown` says which cards pass. The marks are not in here. The next frame builds another.

### frame

<a id="method-frame"></a>

```rust
fn frame(
    pin_on: bool,
    needle: &str,
    ephemeral: &[bool],
    prompts: &[String],
    replies: &[String],

```

The method `frame` builds one [`PinView`](struct.PinView.md) from the pin box and the field.
The flag `pin_on` is the box. The string `needle` is the field. The slice `ephemeral` is the burner flag of each card. The slices `prompts` and `replies` are the card text. The box is on and the field has a pin word when `active` is true. A burner misses. An empty field shows the deck.

The tokens come from `pin_tokens`. `active` is true only when the box is on and the token list is not empty. `shown` starts true for every prompt. An active view then sets each entry from `pin_match`. A missing burner flag is false. A missing reply is empty.

### shows

<a id="method-shows"></a>

```rust
fn shows(&self, index: usize) -> bool
```

The method `shows` reports whether one card is in this frame.
The index `index` is the card. An inactive view returns true for every index. An active view returns the stored flag, and a missing index returns false.

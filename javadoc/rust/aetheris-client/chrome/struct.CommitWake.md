struct CommitWake

The struct `CommitWake` is the result of draining the live session once.
`drain_link` returns it. The window asks for another paint when either flag is set.

The field `show` is true when this drain changed something the window paints.
The field `more` is true when a scope queue or a paint queue still holds a piece.
`commit_wait` uses `more` to choose a short wait while a session is up.

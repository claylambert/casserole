### closed

<a id="method-closed"></a>

```rust
fn closed() -> Self
```

The function `closed` builds a [`ViewFind`](struct.ViewFind.md) with the find bar hidden.
The bar is closed. The needle is empty.
The match list is empty. The current index is `-1`.
The more flag and the arm flag are false.

### shown_count

<a id="method-shown_count"></a>

```rust
fn shown_count(&self) -> String
```

The function `shown_count` formats the find count for the reply window.
The count is a single space when the bar is closed.
The count is a single space when the needle is empty.

An open bar with no matches returns `none`.
Any other bar returns the current place, counting from 1, then ` / `, then the match count.
If more matches exist than the list holds, a `+` is appended.

### on_find_key

<a id="method-on_find_key"></a>

```rust
fn on_find_key(&mut self, hay: &str)
```

The function `on_find_key` handles the find key in one reply window.
`hay` is the reply text the matches are taken from.

If the bar is closed, the bar opens, the arm flag becomes true, and `retarget` runs on `hay`.
If the bar is open and the needle is empty, the arm flag becomes true and the matches stay.
If the bar is open and the needle is not empty, `step` moves to the next match.

### hide_bar

<a id="method-hide_bar"></a>

```rust
fn hide_bar(&mut self)
```

The function `hide_bar` closes the find bar in one reply window.
The open flag becomes false.
The match list is cleared. The current index becomes `-1`.
The more flag and the arm flag become false.
The needle is left as it was.

### retarget

<a id="method-retarget"></a>

```rust
fn retarget(&mut self, hay: &str)
```

The function `retarget` rebuilds the match list for the current needle.
`hay` is the reply text.

The match list is cleared. The more flag becomes false. The current index becomes `-1`.
An empty needle returns with that empty list.

The search walks characters, not bytes. A match uses `same_letter`, so it ignores case.
Matches do not overlap. The next search starts after the matched characters.
Each match stores the byte start and the byte end in `hay`.
The list stops at 2000 matches. A further match sets the more flag and is not stored.
If the list is not empty, the current index becomes 0.

### step

<a id="method-step"></a>

```rust
fn step(&mut self, dir: i32)
```

The function `step` moves the current match forward or backward.
`dir` is the step. A positive value moves forward. A negative value moves backward.

An empty match list returns without a change.
If the current index is negative, it becomes 0.
Otherwise the index increases by `dir`.
An index past the last match wraps to 0.
An index below 0 wraps to the last match.

```rust
struct ConsoleFocus
```

Keyboard focus for the console. The host still owns the line.

[`ConsoleFocus::at_open`](#method-at_open) arms the first paint. [`ConsoleFocus::session_opened`](#method-session_opened)
arms the paint after a session opens. [`ConsoleFocus::take`](#method-take) is that paint.
A click or a drag also takes focus. After the arm fires, a quiet paint
leaves focus where the person put it.

The method `session_opened` arms the paint after a session opens.
`armed` becomes true. The next paint that calls `take` requests the keyboard for the console.

### take

<a id="method-take"></a>

```rust
fn take(&mut self, clicked: bool, drag_started: bool) -> bool
```

The method `take` reports whether this paint should request the keyboard for the console.
`clicked` is true when the console was clicked. `drag_started` is true when a drag started on the console. An armed focus, a click, or a drag returns true.
The arm is cleared before the function returns. A later quiet paint leaves the keyboard where it was put.

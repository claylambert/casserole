# struct PaintHold

[Rust tree](../../index.md) · [aetheris-client](../index.md) · **session**

**Source** `aetheris/rust/aetheris-client/src/session.rs`

```rust
struct PaintHold
```

The `PaintHold` struct keeps paint bytes until the channel is quiet, the burst is old, or the buffer is full.
The caller owns the clock. [`PaintHold::push`](#method-push) does not release because the quiet gap is zero at that instant. [`PaintHold::poll`](#method-poll) releases on the quiet gap or the age cap. [`PaintHold::take`](#method-take) is the immediate flush. An empty push leaves the quiet mark where it was.

### push

<a id="method-push"></a>

```rust
fn push(&mut self, bytes: &[u8], now_ms: u64) -> Option<Vec<u8>>
```

The `push` method stages `bytes` at `now_ms`.
An empty slice returns `None` and leaves the quiet mark where it was. The first byte of a burst stores `now_ms` as the start. `now_ms` is also stored as the last byte time. A buffer of [`HOLD_CAP`](../session.md#constant-hold_cap) bytes or more returns the whole buffer. A start that is [`CAP_MS`](../session.md#constant-cap_ms) old or older returns the whole buffer. A quiet gap does not release inside this method.

### poll

<a id="method-poll"></a>

```rust
fn poll(&mut self, now_ms: u64) -> Option<Vec<u8>>
```

The `poll` method releases the buffer when a cap has elapsed.
An empty buffer returns `None`. The age cap is [`CAP_MS`](../session.md#constant-cap_ms) since the first byte. The quiet gap is [`QUIET_MS`](../session.md#constant-quiet_ms) since the last byte. A full buffer also releases. The returned value is the whole buffer.

### append

<a id="method-append"></a>

```rust
fn append(&mut self, bytes: &[u8])
```

The `append` method joins `bytes` onto the buffer.
The method does not release. The caller uses [`PaintHold::take`](#method-take) for the immediate flush. The mux break uses this path.

### take

<a id="method-take"></a>

```rust
fn take(&mut self) -> Vec<u8>
```

The `take` method returns the buffer and leaves it empty.
The clock marks stay where they were.

### is_empty

The `is_empty` method reports an empty buffer.

### delay_ms

<a id="method-delay_ms"></a>

```rust
fn delay_ms(&self, now_ms: u64) -> Option<u64>
```

The `delay_ms` method returns the milliseconds until the next release.
An empty buffer returns `None`. The value is the sooner of the remaining quiet gap and the remaining age cap. `Some(0)` means [`PaintHold::poll`](#method-poll) is due.

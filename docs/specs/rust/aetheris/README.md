# aetheris

This folder holds the two crates of the Rust Aetheris Client.

aetheris-client is the Rust Aetheris Client crate.

aetheris-term is the terminal crate.

This folder has no requirement page of its own.

The index below names the crates and their module pages.

The Rust folder index is [Rust](../README.md).

The map of the whole spine is [the spine map](../../README.md).

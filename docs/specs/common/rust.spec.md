## 6. Ownership

| Glyphs | Box drawing `┌ ┐ └ ┘ ─ ·`. If the inner label is longer than `columns - 4`, truncate the **model** (keep the timestamp). Pad `─` so both rows are exactly `terminalColumns` |
| Fallback | If we ever need ASCII-only: `+-- 2026-08-26 14:32:05 · model --+` / `+----…----+`. JediTerm/Consolas have the box glyphs; same tofu risk as braille spinner |
| Who | **LLM replies only.** Commands unbannered |
| Body | Unchanged: existing `colorReply` / FormatRouter. Chrome is **not** yellow-wrapped |

### Gotchas (sealed)

- Spinner sits on the prompt line (`CR` + frame + `EL`). Header **after** `stopSpinner` or it overwrites the thinking line.
- Resize mid-session: use `terminalColumns` at write time (already parsed from PTY env; if we never got COLUMNS, 80).
- Very long model ids: truncate model, never wrap the box onto a third line into the reply.
- Failed / empty / cancelled turns: **no** header (nothing received).
- Command output (`status`, `message list`, …): no header.
- Timestamp is server-local. Two Boot hosts will disagree; POC is one host.

## 4. Single-line editor — approved (1-liners only)

Quick-and-dirty convenience. **No wrap, no multiline.**

### Lock

- Track `editCursor` in `0.. lineBuffer.length`.
- **Insert** at cursor (printable keys).
- **Backspace** deletes the character left of the cursor.
- **Delete** (CSI `3~`) deletes the character at/right of the cursor.
- Left/right: CSI `D` / `C`. Home/end: CSI `H`/`F` or `1~`/`4~`, and Ctrl+A / Ctrl+E.
- After any change: existing `redrawInputLine()`, then N `\b` (or CSI `D`) to rest on `editCursor`.
- Up/Down still recall history (cursor at end unless they then move).
- Command-mode green echo: still works via full-line redraw.
- Sealed paste: still atomic (no mid-blob cursor).
- Width-1 BMP chars (POC).

**Out:** wrap, mouse, selection, vi-mode.

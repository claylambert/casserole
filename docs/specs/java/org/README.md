# org

This folder holds the three Java package roots.

org.aetheris is the Java Aetheris Client.

org.casserole is the Casserole Server.

org.roux is Roux.

Roux is the memory package the Casserole Server uses.

This folder has no requirement page of its own.

The index below names those roots and their child pages.

The Java folder index is [Java](../README.md).

The map of the whole spine is [the spine map](../../README.md).

# Java

This folder holds the Java requirements.

The Java Aetheris Client and the Casserole Server are the two Java programs.

Roux is the memory package the Casserole Server uses.

This folder has no requirement page of its own.

The index below names the packages.

The map of the whole spine is [the spine map](../README.md).

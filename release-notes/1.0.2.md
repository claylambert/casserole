# What's new in 1.0.2

Version 1 is the public release. The Maven identifier is `1.0.2`. Maven is the Java build tool. The identifier is the project version that tool packages. The Rust crates `aetheris-term` and `aetheris-client` are `1.0.2`. Those identifiers are version 1. The previous identifier was `1.0.1`. The tag on that copy is `VERSION_1_0_1-2026-11-20-1747`. This page records that identifier move.

These notes are that record. They are not the full notes for version 1. [VERSION.md](../VERSION.md) is the version card. That card says the full notes are not shipped. What moved since identifier `1.0.0` stays [What's new in 1.0.1](1.0.1.md). The tag on that copy is `VERSION_1_0_0-2026-11-19-1218`.

## The identifiers

The Java server is `1.0.2`. The Java client is `1.0.2`. The project version is the `<version>` element in [pom.xml](../pom.xml). Spring Boot writes that value into the packaged jar as `Implementation-Version`.

The Rust crate `aetheris-term` is `1.0.2`. The Rust crate `aetheris-client` is `1.0.2`. The term version is the `version` field in [aetheris-term/Cargo.toml](../rust/aetheris/aetheris-term/Cargo.toml). The client version is the `version` field in [aetheris-client/Cargo.toml](../rust/aetheris/aetheris-client/Cargo.toml). [Cargo.lock](../rust/aetheris/Cargo.lock) names `1.0.2` on those two crates.

[app/start-casserole.ps1](../app/start-casserole.ps1) prints `casserole-server 1.0.2`. [app/start-casserole.sh](../app/start-casserole.sh) prints that same line. [app/start-casserole.zsh](../app/start-casserole.zsh) prints that same line. [app/start-aetheris.ps1](../app/start-aetheris.ps1) prints `aetheris-java 1.0.2`. [app/start-aetheris.sh](../app/start-aetheris.sh) prints that same line. [app/start-aetheris.zsh](../app/start-aetheris.zsh) prints that same line. [rust/aetheris/bin/install.ps1](../rust/aetheris/bin/install.ps1) prints `aetheris-client 1.0.2`. [rust/aetheris/bin/install.sh](../rust/aetheris/bin/install.sh) prints that same line. [rust/aetheris/bin/install.zsh](../rust/aetheris/bin/install.zsh) prints that same line.

A jar that is already built keeps the identifier from the build that packaged it. A binary that is already built keeps the identifier from the build that packaged it. Build again, then start, to carry `1.0.2`.

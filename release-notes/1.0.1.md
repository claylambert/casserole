# What's new in 1.0.1

Version 1 is the public release. The Maven identifier is `1.0.1`. Maven is the Java build tool. The identifier is the project version that tool packages. The Rust crates `aetheris-term` and `aetheris-client` are `1.0.1`. Those identifiers are version 1. The previous identifier was `1.0.0`. The tag on that copy is `VERSION_1_0_0-2026-11-19-1218`. This page lists what moved after that tag. Every enhancement and every fix in that move is named below.

These notes are that list. They are not the full notes for version 1. [VERSION.md](../VERSION.md) is the version card. That card says the full notes are not shipped. A later identifier gets its own file in this directory. This file stays.

## A llama.cpp server

llama-openapi is the Casserole family for a llama.cpp server that speaks the OpenAI chat routes. OpenAI chat is the request shape `POST /v1/chat/completions` and `GET /v1/models`. The Casserole Server implements that client. There is no Spring AI starter for this family.

The long account is [BitNet and the OpenAI-compatible llama server](../bitnet/README.md). BitNet is Microsoft's 1.58-bit model family. A BitNet server is one llama.cpp server this family can call. Another llama.cpp server that speaks those two routes uses this same family. That page is new in identifier `1.0.1`.

The keys live under `spring.ai.llama-openapi`. [LlamaOpenApiProperties](../src/main/java/org/casserole/llm/LlamaOpenApiProperties.java) binds that prefix. The default base is `http://127.0.0.1:3333`. A blank base uses that same address. The example keys are on the long account. [application.yaml](../src/main/resources/application.yaml) is the file the process reads.

Every chat body includes `model`. The value is the text after `llama-openapi/`. [LlamaCppLlmService](../src/main/java/org/casserole/llm/LlamaCppLlmService.java) writes that field after the options are applied. A body that omits `model` is a miss.

The Java Aetheris Client chooses the family in Model Config. The family word is `llama-openapi`. The window is [AetherisNotebookPanel](../src/main/java/org/aetheris/swing/AetherisNotebookPanel.java). The SSH console accepts the same word. The command is `select-model`. The console family is [ChatShell](../src/main/java/org/casserole/ssh/shell/ChatShell.java).

The Rust Aetheris Client chooses this family. The HTTP call stays in the Java server. The family is local. Ollama is the other local family. An air-gap refusal does not apply to either one. The llama-openapi card does not show a think box. `reasoning_content` is the field a thinking model uses for a separate thought channel. The client does not read that field. An empty model returns `no model defined` before the send. A blank API key omits `Authorization`.

## The mood invitation

The mood invitation is the first sentence a mood send gives the model. The sentence is `I'm opening a window with this atmosphere… would you like to step in with me?` The Java constant is `OPENER` in [MoodDesk.java](../src/main/java/org/casserole/mood/MoodDesk.java). The Rust constant is `OPENER` in [mood.rs](../rust/aetheris/aetheris-client/src/mood.rs).

The earlier sentence asked whether to step into it. A stored head that still uses that earlier sentence is recognized. The next send writes the new sentence.

## The context estimate

The llama-openapi heatbar reads `spring.ai.llama-openapi.chat.options.num-ctx`.
`num-ctx` is the context-size key for this family.
A missing key uses 4096.
A stored window of 0 uses 4096.
The method is `heatBudget` on [AetherisNotebookPanel](../src/main/java/org/aetheris/swing/AetherisNotebookPanel.java).
An Ollama row still uses the session window.
A Grok row still uses the window stored for that model id.
A pool row still uses the pool window.

## The SSH typing beat

The SSH typing beat counts keys on the pane before the echo lands.
The listener is `TerminalPanel.addCustomKeyListener` in [SshTerminalPanel](../src/main/java/org/casserole/app/ui/ssh/SshTerminalPanel.java).
A typed character at or above space, other than delete, joins the unsent line.
Backspace drops one character when the line is not empty.
Enter with Shift keeps the line and adds a newline.
Enter without Shift clears the line.
A canvas pane already counted those keys.

## The tokenizer count

A llama-openapi shell prompt is counted with `POST /tokenize`.
The request body is one field, `content`.
The count is the length of the `tokens` array.
A missing `tokens` array is a miss.
A miss keeps a count already stored for that prompt.
A miss with no stored count uses the character guess until the first tokenizer count lands.
Any other engine still calls `countDraft` on [SshClientApp](../src/main/java/org/casserole/app/ui/ssh/SshClientApp.java).

## The prompt stays inside the slot

A llama-openapi send fits the rendered prompt before it posts.
The method is `fitLlamaSlot` in [AmwpFacade](../src/main/java/org/aetheris/ssh/AmwpFacade.java).
The allowance is `num-ctx` minus a positive `num-predict`.
A missing `num-ctx` uses 4096.
A missing `num-predict` leaves the reserve at 0.
The allowance is at least 1.
The measure posts `/apply-template`.
The next post is `/tokenize` on that rendered prompt.
A count at or under the allowance sends that list.
A count over the slot walks the included messages again while the cut gets smaller.
A cut that keeps the same count is refused.
The refusal is `The locked turns do not fit the slot.`
A second miss on the measure is refused.
The refusal is `The slot could not be measured.`
Ollama, Grok, and the pool still use `select`.

## What stayed

Ollama stays `spring.ai.ollama`. Grok stays `POST https://api.x.ai/v1/chat/completions`. The pool stays the Grok agent connection. Those three settings are [Model settings](../casserole-server/README.md#model-settings).

A custom gateway in front of `llama-server` is not built. The Rust window chooses `llama-openapi`. Spring Boot stays `3.5.16`. Spring AI stays `1.1.8`.
